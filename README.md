# Astrology Platform

A full-stack astrology consultation platform built using Laravel, React, MySQL and AI integration.

## Features

### Authentication
- Login
- Register
- Role Based Access Control
- Sanctum Authentication

### Admin Module
- Dashboard Statistics
- Service Management
- Customer Management
- Astrologer Management
- Appointment Management
- Assign Astrologer

### Customer Module
- Book Appointment
- View Appointments
- Edit Profile
- Change Password

### Astrologer Module
- View Assigned Appointments
- Update Appointment Status
- Profile Management

## Technology Stack

### Backend
- Laravel 12
- Sanctum
- MySQL

### Frontend
- React
- Bootstrap 5
- Axios
- React Router

### Database
- MySQL
